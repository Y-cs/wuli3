# order-service 集成验收

本目录规划订单示例的真实基础设施验收，不属于 `wuli3-ddd-generator`。
当前只有验收范围说明，尚未实现可执行集成测试。

## 验收范围

通过真实 MySQL、Redis 和一种消息中间件，验证现有 Starter 的组合使用：

- HTTP 请求、统一响应与错误处理；
- MySQL 数据读写和事务回滚；
- Redis 数据操作与分布式锁；
- MQ 正常发送与接收；
- `afterCommit` 在事务提交时发送、回滚时不发送的行为。

容器编排和测试代码归本目录，示例业务归 `examples/order-service`，不进入生成器模板。

## 可靠性边界

现有远程事件发布属于尽力发送，`afterCommit` 不保证提交后进程崩溃时的消息恢复。
Outbox、持久重试、消费幂等、死信处理和补偿由业务按自身一致性要求实现；
本脚手架不提供通用 Outbox 模块，基础集成验收也不承诺这些可靠性语义。
